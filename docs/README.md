# 구현할 기능 목록

1. 메뉴판 생성
2. 예약 날짜 입력 기능 구현  
2-1. 1~31 범위의 숫자가 아니면, 예외 처리  
2-2. 숫자가 아니면, 예외 처리
3. 메뉴 및 수량 입력 기능 구현  
3-1. 메뉴판에 없는 메뉴면, 예외 처리  
3-2. 중복 메뉴 입력, 예외 처리  
3-3. 수량이 숫자가 아니면, 예외 처리  
3-4. "-"로 구분 하지 않으면, 예외 처리
4. 메뉴 및 수량 출력 기능 구현
5. 할인 전 총 주문 금액 출력 기능 구현
6. 할인 전 총 주문 금액이 12만원 이상일 때, 샴페인 증정 기능 구현
7. 혜택 조건에 맞게 할인 내역(혜택 내역) 출력 기능 구현
8. 할인 내역 합계(총혜택 금액) 출력 기능 구현
9. 할인 후 예상 결제 금액 출력 기능 구현
10. 총혜택 금액에 따라 5,000원, 10,000원, 20,000원 이상시 별, 트리, 산타 출력 기능 구현
